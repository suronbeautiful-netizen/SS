키 복사해 두기

키 글자(AIza…)를 복사한 뒤 카카오톡 ‘나와의 채팅’에 붙여넣어 두세요. 폰에서 쓸 때 꺼내 씁니다.

키 창을 이미 닫았거나 4단계에서 주소를 복사해 키가 지워졌다면, 3단계의 사용자 인증 정보 페이지에서 만든 키 이름을 눌러 다시 복사할 수 있어요.

키는 비밀번호처럼 혼자만 보관하세요. ‘나와의 채팅’은 나만 보는 곳이에요. 단체방·공개 게시판에는 올리지 마세요.

✓ 완료: 키를 ‘나와의 채팅’에 붙여넣어 뒀으면 돼요.

6

탐색기에 키 넣기

안내를 연 앱·탐색기 화면이 이미 열려 있다면 그 화면으로 돌아가 키를 붙여넣으세요.

아직 탐색기를 안 열었다면 여기서 열기 →

  • 설치한 앱은 키가 없으면 설정이 자동으로 열려요. 브라우저에서는 오른쪽 위 ⚙를 누르세요
  • API 키 입력칸에 키 붙여넣기 → 완료
  • 처음 쓰는 검색어를 넣고 검색, 영상이 나오면 성공!

✓ 완료: 처음 쓰는 검색어로 영상이 나오면 성공이에요. (써 본 단어는 저장된 결과가 떠서 확인이 부정확할 수 있어요.)

키는 기기·브라우저마다 따로 저장돼요. 폰과 컴퓨터에서 모두 쓰려면 각각 한 번씩 넣어 주세요.
자주 묻는 질문 오류가 날 때
검색이 안 되고 오류가 떠요
화면 위쪽에 나오는 안내 문구를 먼저 보세요.
  • “API 키가 올바르지 않습니다” → ⚙ 설정에서 키를 다시 붙여넣기
  • “이 주소에서 키 사용이 막혔습니다” → 4단계의 웹사이트 주소 두 개 확인. 저장 후 몇 분 기다려야 할 수도 있어요.
  • “YouTube Data API v3가 꺼져 있습니다” → 2단계에서 사용을 눌렀는지 확인
  • “오늘 할당량을 다 썼습니다” → 하루 한도를 다 쓴 거예요. 한국 시간 오후 4시 또는 5시(계절에 따라 달라요)에 초기화돼요.
검색 한도는 어떻게 세나요?
같은 프로젝트의 키를 쓰는 기기는 하루 100회를 함께 써요. 앱 화면의 ‘오늘 요청한 검색’ 숫자는 그 브라우저에서 센 값이라, 다른 기기에서 쓴 만큼은 빠져 있어요. 정렬 변경에는 횟수가 추가되지 않아요. 같은 검색어도 저장된 결과를 다시 보는 동안(약 30분·최대 8개)에는 추가되지 않지만, 저장 시간이 지나거나 결과가 밀려나면 다시 차감돼요.
왜 어떤 짧은 영상은 안 보이나요?
쇼츠를 거르는 기준이 3분 이하라서 3분 이하의 일반 영상도 함께 빠져요. 공부용으로는 괜찮다고 보고 둔 설정이에요.
정말 공짜인가요?
카드 등록 없이 키를 만들 수 있고, 기본 한도 안에서는 요금이 붙지 않아요. 결제 계정을 연결하지 않았다면 한도를 넘겨도 요금이 아니라 그날 검색이 막힐 뿐이에요.
